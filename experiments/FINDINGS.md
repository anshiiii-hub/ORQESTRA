## Limits and unfinished work

Single machine; deterministic millisecond agents; delays injected after the handler returns and before publication; injected faults are not real-world fault rates; short leases used for speed. Concurrent isolated trials contend for the same host and PostgreSQL server. No external side effects, network partitions, lease renewal, automatic retries after agent errors, or real-world workloads were studied. Production idle polling is one second; the harness uses 20 ms to bound runtime. Schema creation uses current application metadata, not a migration-path experiment. No 10-second trials or inference about routing, LLM quality, or the 78-case benchmark.

Docker was installed but its daemon was unavailable. The existing suite ran through the local Python equivalent; before/after results are recorded separately. Environment and exact commands are in README.md. P-values are unadjusted and multiple comparisons limit their interpretation.
